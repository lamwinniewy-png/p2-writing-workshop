# Susu & Neko's Writing Workshop

Interactive P.2 English writing revision for SPPCS Writing 1–3:

1. My Favourite Place at School
2. Rules in Places like Home
3. A Magazine Article: My Favourite Season

Includes model writing with read-aloud, games, planners, a paper-writing timer and checklists, a Fix-it Lab based on teacher corrections, exam practice and a sticker book. Progress is saved on the device.
